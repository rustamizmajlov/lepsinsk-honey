# Use cases (пользовательские истории) — SkillSwap

Формат: **Как &lt;роль&gt; я хочу иметь возможность &lt;действие&gt;, чтобы &lt;ценность&gt;.**

Роли:
- **Гость** — неавторизованный посетитель;
- **Пользователь** — зарегистрированный участник; в каждом обмене выступает как *ученик* (отправляет заявку) или как *преподаватель* (владелец навыка);
- **Администратор** — пользователь с ролью `admin`.

Обозначения:
- **MVP** — история входит в минимально жизнеспособный продукт (всего 20);
- ✅ — реализовано в текущей версии, 🟡 — реализовано частично (есть API, нет UI), 🔜 — в бэклоге.
