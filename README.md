# 🍯 Лепсинский мёд — интернет-магазин пасеки

Веб-приложение для небольшой семейной пасеки из села Лепсинск (область Жетысу, Казахстан).
Покупатели выбирают мёд, оформляют заказ с доставкой и следят за его статусом.
Пасечник (администратор) ведёт каталог, остатки и заказы и видит статистику продаж.

> Учебный проект: пасека, товары, цены и демо-заказ вымышлены.

📄 Описание проекта — [docs/PROJECT.md](docs/PROJECT.md)
📋 60 use cases (20 MVP) — [docs/USE_CASES.md](docs/USE_CASES.md)
🔌 REST API — [docs/API.md](docs/API.md)

## Из чего состоит

| Часть | На чём написана | Что делает |
|---|---|---|
| **Сервер** | C++17 | Принимает запросы, проверяет права, считает заказы, работает с базой |
| **База данных** | PostgreSQL | Хранит пользователей, товары и заказы |
| **Интерфейс** | HTML, CSS, JavaScript | Страницы сайта в браузере |

Каждая часть запускается в своём **Docker-контейнере**.

## Возможности

- Каталог мёда: поиск, фильтр по сорту, сортировка по цене, карточка товара
- Подбор мёда по вкусу — тест из 3 вопросов
- Корзина, три способа доставки, бесплатная доставка от 20 000 ₸
- **CRUD заказов**: оформить, посмотреть, изменить или отменить новый заказ, удалить
- **CRUD товаров** в панели пасечника: добавить, изменить цену и остаток, скрыть, удалить
- Статистика: выручка, сколько мёда продано, хиты, заканчивающиеся товары
- Вход по логину и паролю, роли **user** (покупатель) и **admin** (пасечник)

## Запуск через Docker

```bash
git clone https://github.com/rustamizmajlov/lepsinsk-honey.git
cd lepsinsk-honey
docker compose up --build
```

Сайт откроется по адресу http://localhost:8080.

## Запуск без Docker (Windows)

Нужен компилятор C++ **MinGW-w64 (g++)** — например, с https://winlibs.com (папку `bin` добавить в PATH).

1. Скачайте проект: **Code → Download ZIP** и распакуйте.
2. Дважды кликните **`run-local.bat`**.

При первом запуске сервер компилируется — это занимает несколько минут. Потом сайт сам откроется
в Brave (или в браузере по умолчанию) по адресу http://localhost:8080. Следующие запуски — за пару секунд.
Пока открыто окно консоли, сайт работает; закрыли окно — сайт выключился.

## Структура проекта

```
lepsinsk-honey/
├── backend/                  # сервер на C++
│   ├── src/
│   │   ├── main.cpp          # запуск сервера
│   │   ├── db.hpp            # общий интерфейс базы данных
│   │   ├── db_postgres.cpp   # PostgreSQL (Docker)
│   │   ├── db_sqlite.cpp     # SQLite (запуск без Docker)
│   │   ├── security.hpp      # хеширование паролей, токены
│   │   ├── app.hpp / app.cpp # общие помощники
│   │   ├── routes_auth.cpp   # регистрация и вход
│   │   ├── routes_products.cpp  # CRUD товаров
│   │   ├── routes_orders.cpp    # CRUD заказов
│   │   ├── routes_admin.cpp     # пользователи и статистика
│   │   └── schema.cpp        # таблицы и демо-данные
│   ├── third_party/          # библиотеки: cpp-httplib, nlohmann/json, SQLite
│   └── Dockerfile
├── frontend/                 # интерфейс
│   ├── public/               # index.html, app.js, styles.css
│   ├── nginx.conf
│   └── Dockerfile
├── docs/                     # описание, use cases, API
├── tests/api_test.py         # проверка API
├── docker-compose.yml
└── run-local.bat             # запуск без Docker
```
