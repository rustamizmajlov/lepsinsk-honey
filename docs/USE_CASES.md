# Use cases (пользовательские истории) — «Лепсинский мёд»

Формат: **Как &lt;роль&gt; я хочу иметь возможность &lt;действие&gt;, чтобы &lt;ценность&gt;.**

Роли:
- **Гость** — посетитель сайта без входа;
- **Покупатель** — зарегистрированный пользователь (роль `user`);
- **Пасечник** — администратор магазина (роль `admin`).

Обозначения: **MVP** — история входит в минимально жизнеспособный продукт (всего 20);
✅ — реализовано, 🔜 — в бэклоге.
